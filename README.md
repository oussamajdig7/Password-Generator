# Secure Password Generator 🔐

A secure and customizable CLI password generator written in Python. It uses Python's built-in `secrets` module to ensure cryptographically secure random generation.

## Features

- 🔒 **Cryptographically Secure**: Built with Python's `secrets` module.
- ⚙️ **Customizable**: Choose password length, quantity, and include/exclude uppercase, lowercase, numbers, and symbols.
- 🚀 **Zero External Dependencies**: Uses only standard Python libraries (`secrets`, `string`).

## Requirements

- Python 3.6+
- No additional external packages required!

## Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/oussamajdig7/Password-Generator.git
   cd Password-Generator
   ```

2. Run the program:
   ```bash
   python main.py
   ```
